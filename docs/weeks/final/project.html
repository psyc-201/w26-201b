Final Project

Overview

The final project is your opportunity to apply the statistical modeling skills you’ve learned throughout the course to a real dataset. Your deliverable is a publication-quality abstract, methods section, and results section — the kind you’d submit to a journal — rendered as a reproducible .qmd document with all supporting code.

Tip

Looking for data? Check out the Open Datasets page for a curated collection of publicly available datasets.

Project Options

Important

In all cases, you must choose a new question to answer — not something you or someone else has previously analyzed. The dataset can be familiar, but the research question must be original.

Solo or Group

You may work solo or in a group. If working in a group, see the additional requirements below.

Dataset

Regardless of solo or group, choose one of the following:

  1. Existing dataset from your 201A or first-year project — a dataset you already have access to from prior coursework or your first-year research
  2. Existing dataset in your lab — data your lab has collected that you have permission to use
  3. New open dataset — find one from the Open Datasets page
  4. New simulated dataset — generate synthetic data to answer your question (discuss with instructors first)

Group Requirements

Groups may provide a single submission, but you must:

  • Include a CRediT author statement describing each member’s contributions
  • Demonstrate evidence of collaboration via GitHub — each person must contribute at least 1 commit to the project repository

Requirements

1. Research Question

Formulate a clear, answerable research question that requires statistical analysis.

2. Analysis

Your analysis should include:

  1. Exploratory Data Analysis — Summary statistics, visualizations, data quality assessment
  2. Statistical Modeling — At least one model from the course (GLM, LMM, etc.) with diagnostics and comparison (if appropriate)
  3. Inference or Prediction — Parameter estimates with uncertainty, hypothesis tests or confidence intervals, OR cross-validated prediction performance
  4. Interpretation — What do the results mean? Limitations and future directions

3. Deliverables

Your submission is a GitHub repository containing all of the following:

  1. Reproducible Python environment — pyproject.toml + README with instructions so anyone can reproduce your work
  2. Quarto document — A rendered .qmd file with publication-quality:
    • Abstract (~150-250 words)
    • Methods (see rubric below)
    • Results with relevant figures, tables, and references
  3. Data files and analysis scripts — with informative descriptions in the README
    • Separate raw data from any preprocessed/cleaned data you create
    • If datasets are too large for GitHub (>5 MB), provide a download link and retrieval instructions in the README so someone can still reproduce your work

Proposal Template

Submit a 1-page proposal via GitHub Classroom including:

  1. Research question (1-2 sentences)
  2. Data source (what data, where from, sample size)
  3. Proposed analysis (what models/methods)
  4. Expected challenges (what might be tricky?)

Collaboration & GenAI Policy

Whether working solo or in a group, you are welcome to discuss ideas, troubleshoot code, and give feedback with classmates outside your group — but all submitted writing and analysis must be your own (or your group’s). If you use GenAI tools, the course GenAI policy applies — include a transcript with your submission.

Example Projects

Past successful projects have included:

  • Predicting movie ratings with mixed models (repeated measures per user)
  • Analyzing experimental psychology data with factorial ANOVA/LMM
  • Logistic regression for predicting customer churn from survey data
  • Bootstrap power analysis for a planned study
  • Factor analysis of survey responses with model comparison

Analytical Approach: Statistical models justified with clear rationale; specifies assumption checks, alpha levels, and software/packages used. Sufficient detail for an independent researcher to reproduce the analysis All major components present with some details missing. Variables adequately described. Analytical choices mostly justified. Minor gaps that wouldn’t prevent replication Key information present but lacks depth. Some variables poorly described. Limited justification for analytical choices. Replication would be challenging Major components missing or inadequate. Insufficient detail for understanding the analysis. No justification for analytical decisions. Replication not possible

Results: All analyses clearly reported with complete statistics (test statistics, df, p-values, effect sizes, CIs); figures and tables enhance understanding. Interpretation: Accurate; avoids over-interpreting null results; appropriately cautious with causal language. Limitations: Thoughtful discussion of methodological and statistical limitations, including threats to validity Most assumptions checked appropriately. Results clearly reported with minor omissions. Interpretation generally sound with appropriate caution. Limitations discussed but may lack depth or miss key issues Basic assumption checking but incomplete. Results reported but missing key statistics (e.g., no effect sizes or CIs). Some understanding shown but may over-interpret. Limitations mentioned but superficial Assumptions not checked or inadequately addressed. Results poorly reported or incomplete. Misinterpretation of findings. Limitations absent or lacking understanding
